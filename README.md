# 📅 Daily Note Agent (업무일지 자동화 에이전트)

매일 아침 출근 시, 나만의 업무일지 양식을 자동으로 생성하고 메모장으로 띄워주는 파이썬 자동화 스크립트입니다.

## 🚀 주요 기능
- **주간 파일 자동 생성:** 해당 주차의 업무일지 파일(`YYYY년_M월_W주차_업무일지.txt`)이 없으면 템플릿에 맞게 새로 생성합니다.
- **일간 할 일(Today) 자동 추가:** 주간 파일이 이미 있으면 `<!-- DAILY_INSERT_MARKER -->` 위치에 오늘 날짜 섹션만 끼워 넣습니다. (같은 날 두 번 실행해도 중복 추가되지 않습니다.)
- **자동 팝업:** 작업이 끝나면 즉시 Windows 메모장(Notepad)으로 해당 파일을 열어줍니다.

---

# ⚙️ 실행 방법 (처음부터 끝까지)

## 0단계. 내 PC에 Python이 있는지 확인

PowerShell(또는 명령 프롬프트)을 열고 아래를 입력합니다.

```powershell
python --version
```

- `Python 3.13.1` 처럼 **버전이 찍히면** → 설치 완료 상태. 1단계는 건너뛰고 2단계로 갑니다.
- `Python was not found; run without arguments to install from the Microsoft Store...` 라고 나오면 → **설치가 안 된 상태입니다.** Windows에는 `python.exe`라는 이름의 *가짜 바로가기*(앱 실행 별칭)가 기본으로 들어 있어서, 설치를 안 했는데도 명령어 자체는 인식되는 것처럼 보입니다. 1단계를 진행하세요.
- 창이 그냥 닫히거나 Microsoft Store가 뜨는 경우도 **설치 안 된 상태**입니다.

## 1단계. Python 설치 (설치되어 있다면 건너뛰기)

1. https://www.python.org/downloads/ 접속 → 노란색 **Download Python 3.x.x** 버튼 클릭
2. 받은 설치 파일(`python-3.x.x-amd64.exe`) 실행
3. ⚠️ **첫 화면 맨 아래 `Add python.exe to PATH` 체크박스를 반드시 켭니다.** (이걸 놓치면 나중에 `python` 명령어를 못 찾습니다.)
4. **Install Now** 클릭 → 완료되면 **열려 있던 PowerShell 창을 모두 닫고 새로 엽니다.** (PATH는 새 창부터 반영됩니다.)
5. 다시 `python --version` 을 쳐서 버전이 나오는지 확인합니다.

> Microsoft Store 버전 Python도 동작은 하지만, 나중에 작업 스케줄러에 등록할 때 경로 문제가 생기기 쉬워서 **python.org 설치본을 권장**합니다.

## 2단계. 소스 받기

이미 폴더가 있다면 건너뛰고, 다른 PC에서 새로 받는 경우:

```powershell
git clone https://github.com/Eunjinshin/worklog-automator.git
cd worklog-automator
```

## 3단계. 수동 실행해보기 (동작 확인)

**중요:** 이 스크립트는 `업무일지` 폴더를 **"현재 작업 디렉토리(현재 터미널이 위치한 폴더)" 기준**으로 만듭니다. 따라서 반드시 **스크립트가 있는 폴더로 이동한 뒤** 실행해야 파일이 엉뚱한 곳에 생기지 않습니다.

```powershell
cd "C:\Users\user\Desktop\AI_ㅍ프로젝트\01. 업무일지 자동화"
python daily_note_agent_v2.py
```

정상적으로 실행되면 터미널에 이런 메시지가 뜨고, 곧바로 메모장이 열립니다.

```text
폴더가 생성되었습니다: ...\업무일지
새로운 주간 파일 생성됨: 2026년_8월_3주차_업무일지.txt
메모장을 실행했습니다.
```

같은 날 한 번 더 실행하면 `오늘 날짜의 할 일 섹션이 이미 존재합니다.` 라고 뜨면서 메모장만 다시 열립니다. (중복 걱정 없이 여러 번 눌러도 안전합니다.)

## 4단계. 더블클릭으로 실행하기 (배치 파일)

매번 터미널을 여는 게 번거로우면, 같은 폴더에 있는 **`run_daily_note.bat` 파일을 더블클릭**하면 됩니다. 이 배치 파일은 작업 디렉토리를 스크립트 위치로 고정해주기 때문에, 바탕화면에 바로가기를 만들어 두고 아무 데서나 눌러도 `업무일지` 폴더가 항상 같은 자리에 생깁니다.

> 바탕화면 바로가기 만들기: `run_daily_note.bat` 우클릭 → **보내기 → 바탕 화면(바로 가기 만들기)**

## 5단계. 매일 아침 자동 실행 (Windows 작업 스케줄러)

1. 시작 메뉴에서 **작업 스케줄러** 검색 → 실행
2. 오른쪽 **작업 만들기...** 클릭 (※ '기본 작업 만들기'가 아니라 **'작업 만들기'** 를 선택해야 아래 옵션들을 지정할 수 있습니다)
3. **[일반] 탭**
   - 이름: `업무일지 자동 생성 에이전트`
   - 보안 옵션: **`사용자가 로그온할 때만 실행`** 을 선택합니다.
     ⚠️ `로그온 여부에 관계없이 실행`을 고르면 메모장이 백그라운드에서 보이지 않게 실행되어 화면에 안 뜹니다.
4. **[트리거] 탭 → 새로 만들기**
   - 작업 시작: `일정에 따라` / `매일`
   - 시간: 오전 `08:50` (본인 출근 시간에 맞게)
   - 확인
5. **[동작] 탭 → 새로 만들기**
   - 작업: `프로그램 시작`
   - **프로그램/스크립트:** `run_daily_note.bat` 의 전체 경로
     예) `C:\Users\user\Desktop\AI_ㅍ프로젝트\01. 업무일지 자동화\run_daily_note.bat`
   - **시작 위치(옵션):** 스크립트가 들어 있는 **폴더 경로** (따옴표 없이 입력)
     예) `C:\Users\user\Desktop\AI_ㅍ프로젝트\01. 업무일지 자동화`
     ⚠️ 이 칸을 비우면 작업 디렉토리가 `C:\Windows\System32`가 되어 **업무일지 폴더가 System32 안에 생깁니다.** 반드시 채워주세요.
6. **[조건] 탭**
   - `컴퓨터의 AC 전원이 켜져 있는 경우에만 작업 시작` 체크 해제 (노트북이라면 배터리 상태에서도 실행되도록)
7. **확인** → 목록에서 방금 만든 작업을 우클릭 → **실행** 을 눌러 바로 테스트해봅니다. 메모장이 뜨면 성공입니다.

## 🧩 문제 해결 (Troubleshooting)

| 증상 | 원인 / 해결 |
| --- | --- |
| `Python was not found...` 메시지 | Python 미설치. 1단계 진행 후, 새 터미널 창에서 다시 실행 |
| `python`은 되는데 `py`는 안 됨 (또는 반대) | 둘 중 되는 명령어를 쓰면 됩니다. 배치 파일 안의 `python`을 `py`로 바꿔도 무방합니다 |
| 업무일지 폴더가 엉뚱한 위치에 생김 | 작업 디렉토리 문제. 4단계 배치 파일로 실행하거나, 스케줄러의 **시작 위치**를 채웠는지 확인 |
| 스케줄러는 "성공"인데 메모장이 안 뜸 | [일반] 탭에서 `사용자가 로그온할 때만 실행`이 선택됐는지 확인 |
| 메모장에서 한글/이모지가 깨짐 | 파일은 UTF-8로 저장됩니다. 최신 Windows 10/11 메모장은 정상 표시되며, 깨진다면 메모장에서 `다른 이름으로 저장 → 인코딩: UTF-8` 로 한 번 저장하면 해결됩니다 |
| 검은 창이 잠깐 떴다가 사라짐 | 정상 동작입니다(배치 파일 실행 후 종료). 에러를 보고 싶으면 터미널에서 3단계 명령으로 직접 실행하세요 |

## 🔧 저장 위치 바꾸기

기본값은 스크립트 실행 폴더 아래 `업무일지\` 입니다. 다른 경로에 쌓고 싶다면 `daily_note_agent_v2.py` 24번째 줄을 수정하세요.

```python
# 변경 전
target_dir = os.path.join(os.getcwd(), "업무일지")

# 변경 후 (예: D 드라이브 고정 경로)
target_dir = r"D:\업무일지"
```
