# 📅 Daily Note Agent (업무일지 자동화 에이전트)

매일 아침 출근 시, 나만의 업무일지 양식을 자동으로 생성하고 메모장으로 띄워주는 파이썬 자동화 스크립트입니다.

## 🚀 주요 기능
- **주간 파일 자동 생성:** 해당 주차의 업무일지 파일(`YYYY년_M월_W주차_업무일지.txt`)이 없으면 템플릿에 맞게 새로 생성합니다.
- **일간 할 일(Today) 자동 추가:** 기존 주간 파일이 존재하면, 하단에 오늘 날짜와 할 일 목록 포맷만 자동으로 추가합니다.
- **자동 팝업:** 스크립트 실행 완료 후 즉시 Windows 메모장(Notepad)을 실행하여 해당 파일을 띄워줍니다.

## 🛠️ 환경 및 사전 준비
- Python 3.x 이상
- Windows OS (메모장 자동 실행 기능 사용 시)

## ⚙️ 설치 및 자동화 세팅 (Windows 작업 스케줄러)
매일 아침 출근 시간에 스크립트가 자동으로 실행되도록 설정하는 방법입니다.

1. `daily_note_agent_v2.py` 파일을 원하는 디렉토리에 위치시킵니다.
2. Windows 시작 메뉴에서 **'작업 스케줄러'**를 검색하여 실행합니다.
3. 우측 **'기본 작업 만들기'** 클릭
   - **이름:** 업무일지 자동 생성 에이전트
   - **트리거:** 매일 / 오전 08:50 (본인 출근 시간에 맞게 설정)
   - **작업:** 프로그램 시작
   - **프로그램/스크립트:** `python` (환경변수 설정이 안 되어 있다면 `python.exe`의 절대 경로 입력)
   - **인수 추가(옵션):** `daily_note_agent_v2.py`
   - **시작 위치(옵션):** 스크립트가 저장된 폴더 절대 경로 (예: `C:\Users\Username\workspace\daily-note-agent\`)
4. 마침을 누르면 세팅 완료! 내일 아침부터 메모장이 자동으로 열립니다.
